# BarbellVBT 增强简洁版（0.2.0）

这是一个基于 Kivy + OpenCV 的 Android 杠铃视频分析实验原型。无需在电脑安装开发环境；上传到 GitHub 后，由 GitHub Actions 自动尝试构建 Android Debug APK。

## 这版新增的功能

1. **动作类型**：深蹲、前蹲、硬拉、高翻、抓举、卧推、其他。
2. **训练信息**：可以填写训练者和杠铃负荷（kg）。
3. **标记颜色选择**：红/橙、蓝、黄、绿；红/橙为默认推荐。
4. **视频分析**：选择 MP4、AVI、MOV、MKV、3GP 视频，逐帧追踪彩色标记。
5. **每段数据**：平均速度、峰值速度、垂直行程、持续时间、开始/结束时间。
6. **速度变化**：将每个运动片段的平均速度与本视频最快片段比较，计算相对速度下降百分比。
7. **识别质量提示**：显示彩色标记被识别到的帧占视频总帧数的比例，并提示检查视频质量。
8. **训练记录**：可将训练者、动作、负荷、视频名称、分析结果保存到手机 App 私有目录；可查看最近 20 次记录（最多保留 100 次）。
9. **CSV 导出**：导出训练信息和各动作段数据，方便用 Excel 做进一步分析。
10. **标定设置**：自定义像素/米换算比例。

## 使用步骤

1. 用醒目胶带在杠铃片或杠铃端部贴一个颜色标记。
2. 把手机固定在三脚架上，从杠铃侧面拍摄，尽量避免透视角度和遮挡。
3. 打开 App，选择动作类型，填写训练者/负荷（可以不填）。
4. 选择与标记相同的颜色，选择训练视频。
5. 根据视频画面中的已知尺寸设置像素/米标定值。
6. 点击“开始分析”，查看摘要和各动作段数据。
7. 点击“保存训练记录”保存到本机，或点击“导出 CSV”。

## GitHub 自动打包

最简单方式是：创建一个 GitHub 仓库，将本文件夹中的**所有内容**直接上传到仓库根目录，提交到 `main` 分支。确认仓库首页直接显示 `main.py` 与 `buildozer.spec`，且有 `.github/workflows/build.yml`。然后打开 Actions，查看 `Build BarbellVBT Android APK` 工作流。成功后，在任务详情底部的 Artifacts 下载 `BarbellVBT-Enhanced-debug-APK`。

完整零基础点击步骤见：`00_零基础操作教程_增强版.txt`。

## 测量方法与重要限制

- 本程序通过 HSV 颜色阈值识别画面中的彩色标记，再由标记中心点纵向位移和视频时间戳估算速度。
- 目前展示的是**连续运动片段**，并不保证每个片段都等于一次有效重复动作（rep）。
- 当前没有可靠地区分向心与离心，也没有从负荷与动作阶段计算经验证的机械功率。
- “相对最快片段速度下降”是本视频内的数值比较，不是疲劳诊断，也不能单独用来决定是否减重或结束训练。
- 标记覆盖率只表示每帧是否找到符合颜色阈值的区域，不等同于追踪准确率；背景中出现同色物体也可能被误识别。
- 结果受相机角度、标定平面、镜头透视、帧率、遮挡、光照、颜色标记尺寸影响。
- 尚未完成 Android 真机兼容性验证，也没有与 GymAware、Tendo、线性位置传感器等设备完成效度/信度比较。请先作为学习和开发原型使用，不要直接作为专业训练负荷决策依据。

## 技术与依赖

- Python 3.11.9
- Kivy 2.3.0
- NumPy
- OpenCV（通过 python-for-android 的 `opencv` recipe 构建）
- Android min API 24（当前 python-for-android NumPy recipe 要求）
- Buildozer + python-for-android

不要把 requirements 中的 `opencv` 改成 `opencv-python` 或 `opencv-python-headless`。python-for-android 对含原生编译组件的依赖需要对应 recipe：<https://python-for-android.readthedocs.io/en/latest/recipes.html>
