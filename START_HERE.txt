============================================================
BarbellVBT 增强简洁版：零基础 GitHub 自动打包教程
============================================================

先告诉你结果：你不需要会 Python，不需要安装 Android Studio，也不需要在电脑上运行代码。
你只需要：下载压缩包 -> 解压 -> 上传 GitHub -> 等它打包 -> 下载 APK。

------------------------------------------------------------
第 1 步：下载并解压文件
------------------------------------------------------------

1. 下载我发给你的“BarbellVBT_增强简洁版_完整项目.zip”。
2. 在电脑“下载”文件夹找到它。
3. 对着 ZIP 文件点鼠标右键。
4. 选择“全部解压”。
5. 解压后打开文件夹“BarbellVBT_增强简洁版”。

你应该能看到：

  main.py                         程序主文件
  buildozer.spec                  安卓打包设置
  README.md                       项目说明
  make_assets.py                  图标生成脚本（不需要手动运行）
  assets                          App 图标和启动图片
  .github                         GitHub 自动打包设置（非常重要）
  00_零基础操作教程_增强版.txt     本说明

最重要：main.py 和 buildozer.spec 必须直接在这个文件夹里面。
不要把里面这些东西再套进一个新的文件夹后上传。

------------------------------------------------------------
第 2 步：打开 GitHub 并创建一个“仓库”
------------------------------------------------------------

1. 打开浏览器，在地址栏输入：https://github.com
2. 登录你的 GitHub 账号。没有账号就先注册。
3. 登录后，在网页右上角找到“+”号并点击。
4. 点击菜单中的“New repository”。
5. 在 Repository name（仓库名称）填写：

      BarbellVBT

6. Description 可以不填。
7. Public 和 Private 任选一个：
   - Public：代码公开，别人可以看见。
   - Private：代码不公开。
8. 不要勾选“Add a README file”。
9. 点击下面绿色的“Create repository”。

现在你创建好了一个网上文件夹，下一步把项目文件放进去。

------------------------------------------------------------
第 3 步：把电脑里的项目上传到 GitHub
------------------------------------------------------------

1. 新页面里点击“Add file”。
2. 再点击“Upload files”。
3. 回到电脑，打开刚解压的“BarbellVBT_增强简洁版”文件夹。
4. 在文件夹空白处点一下，按键盘 Ctrl + A（全选）。
5. 把选中的文件和文件夹，直接拖到 GitHub 网页中间的上传区域。
   注意：上传解压后的内容，不是上传 ZIP 压缩包本身。
6. 等待上传完成。
7. 页面下方找到“Commit changes”。
8. 提交说明填写：

      Upload BarbellVBT enhanced project

9. 选择“Commit directly to the main branch”。
10. 点击绿色“Commit changes”。

上传完成后，回到仓库首页，检查：

  main.py
  buildozer.spec
  README.md
  assets 文件夹
  .github 文件夹

特别注意：
- main.py 应该直接显示在仓库首页，不要点进某个同名文件夹才能看到。
- .github 是一个以点开头的隐藏目录。Windows 资源管理器可能隐藏它；如看不到，打开“查看”菜单，开启“隐藏的项目”。
- 如果 GitHub 没上传 .github，可以单独上传该文件夹。

------------------------------------------------------------
第 4 步：让 GitHub 自动打包 APK
------------------------------------------------------------

1. 在仓库网页上方点击“Actions”。
2. 左侧找到：

      Build BarbellVBT Android APK

3. 点击它，查看是否有一条正在运行的任务。
4. 如果没有任务：
   - 点击左侧工作流名称；
   - 找到右上方“Run workflow”；
   - Branch 选 main；
   - 再点击绿色“Run workflow”。
5. 点进任务后，找到“Build Android APK”步骤。

状态怎么看：
- 黄色圆圈：还在打包。
- 绿色对勾：打包成功。
- 红色叉号：打包失败，需要查看报错。

第一次打包要下载 Android SDK、NDK、Python、Kivy 和 OpenCV 等组件。
第一次会明显慢一些。请不要因为几分钟没动静就关掉页面。

大致时间预估（不是保证时间）：
- 第一次从零开始构建：建议预留 45 到 120 分钟。
- 如果 OpenCV 编译或下载比较慢，可能接近 3 小时；本项目工作流的单次上限是 180 分钟。
- 之后重新上传代码再打包，仍可能需要几十分钟，因为 GitHub 每次任务不一定保留完整编译环境。
- APK 已经生成后，从 Artifacts 下载 ZIP 通常只需要几十秒到几分钟，主要取决于文件大小和你的网速。

注意：如果红色叉号出现，等待再久也不会自动变成功。点进去查看真正报错步骤，复制最后 30-60 行给 ChatGPT。

------------------------------------------------------------
第 5 步：下载 APK 文件
------------------------------------------------------------

1. 等任务出现绿色对勾。
2. 点击这条成功的任务。
3. 在任务详情页往下找“Artifacts”。
4. 点击：

      BarbellVBT-Enhanced-debug-APK

5. 浏览器会下载一个 ZIP 文件。
6. 在电脑下载文件夹中找到这个 ZIP，右键 -> 全部解压。
7. 找到里面以 .apk 结尾的文件。
8. 将 APK 发送到安卓手机（USB、网盘、微信文件传输等均可）。
9. 手机上点击 APK 安装。
10. 若系统提示“不允许安装未知应用”，按手机页面指引允许当前文件管理器安装应用。

注意：APK 只能安装在 Android 手机上，不能装在 iPhone 上。

------------------------------------------------------------
第 6 步：手机 App 怎么使用
------------------------------------------------------------

【第一部分：训练信息】

1. 打开 App。
2. 训练者可以填名字，也可以不填。
3. 选择动作：深蹲、前蹲、硬拉、高翻、抓举、卧推、其他。
4. 填写杠铃负荷（kg），不填也可以。

【第二部分：拍摄和选择视频】

1. 在杠铃片或杠铃端部贴醒目的彩色胶带。
2. 建议先用红色或橙色胶带。
3. 手机固定在三脚架上，从杠铃侧面拍摄。
4. 打开 App，选择“红/橙（推荐）”。
5. 点击“选择训练视频”，选择 MP4 等视频文件。

【第三部分：标定】

标定是把“画面像素”换算成“真实米数”。
例如：
- 杠铃片真实直径是 0.45 米；
- 在画面里量出来是 90 像素；
- 那么像素/米 = 90 ÷ 0.45 = 200。

将 200 填入标定设置。
注意：标定物体和杠铃运动轨迹尽量处于同一平面，否则误差可能很大。
如果不清楚怎么测，可以先用默认值做界面测试，不要把默认值当成准确标定。

【第四部分：分析和导出】

1. 点击“开始分析”。
2. 等待分析完成。
3. 看本次摘要：平均速度、最高峰值速度、运动片段数量、标记识别覆盖率。
4. 下方可以看每个动作段的平均速度、峰值速度、垂直行程、时长和相对最快段速度下降。
5. 点击“保存训练记录”，可把本次结果保存到手机 App 私有目录。
6. 点击“查看本机历史记录”，查看最近 20 次训练。
7. 点击“导出 CSV”，导出表格，方便在 Excel 中查看。

说明：Android 当前版本的 CSV 先保存在 App 私有文件夹内，暂未提供系统分享/保存到公共下载目录按钮。

------------------------------------------------------------
如果 GitHub 打包失败，怎么把错误发给 ChatGPT？
------------------------------------------------------------

1. 打开仓库网页 -> Actions。
2. 点击红色叉号的任务。
3. 找到“Build Android APK”步骤并点开。
4. 往下找到真正报错的位置。
5. 复制最后 30-60 行错误文字，或者直接截图发给 ChatGPT。

常见问题：

A. Actions 页面没有任何任务：
   检查仓库首页有没有 .github/workflows/build.yml；确认已提交到 main 分支；确认 Actions 没被禁用。

B. 报错找不到 main.py 或 buildozer.spec：
   上传时多套了一层文件夹。回仓库首页确认这两个文件直接显示。

C. 报错包含 opencv / numpy / NDK：
   把错误截图或文字发来，不要自行改依赖版本。

D. 打包成功但手机选不到视频：
   检查系统是否允许视频访问；不同 Android 品牌和版本的文件访问方式可能不同。发手机型号、系统版本和报错截图。

------------------------------------------------------------
当前版本功能边界（请务必看）
------------------------------------------------------------

这是增强版实验原型，不是已经通过验证的商业 VBT 仪器。

已经加入：
- 动作类型、训练者、负荷信息；
- 颜色标记选择（红/橙、蓝、黄、绿）；
- 视频追踪与连续运动片段分析；
- 平均速度、峰值速度、位移、持续时间；
- 相对最快动作段的速度下降百分比；
- 标记识别覆盖率和简单结果提示；
- 本机训练历史；
- CSV 导出。

还没有做到：
- 实时摄像头测量；
- AI 自动识别整根杠铃；
- 保证每个运动片段就是一次标准 rep；
- 准确区分向心速度和离心速度；
- 经过校准的机械功率、负荷推荐；
- 与 GymAware 等专业设备完成效度和信度验证。

不要仅凭此 App 的结果决定运动员训练负荷。建议先用容易看清楚的测试视频做重复对比，并和人工逐帧核对。
